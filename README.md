## 概要
本サービスは、利用者の端末に搭載された **加速度センサー** を用いて  
**加速度** や **簡易的な震度** を計測し、その情報を送信できる仕組みです。  

送信された情報は [P2P強震モニタ](https://turbowarp.org/1222718936)にて処理され、  
**誰でも閲覧することができます。**




## 使い方
1. [ウェブサイト](https://anesewo.github.io/P2Pkyousin/) にアクセスしてください。  
   （※一部端末やブラウザでは使用できない場合があります）  

2. 画面上には以下が表示されます：
   - **直近60秒間のNS（南北）・EW（東西）・UD（上下）方向の加速度波形**
   - **直近60秒間の加速度波形から求めた計測震度(相当値)**
   - **直前の平面方向(NS,EW方向)の加速度から求めたリアルタイム加速度**
   - **速度・加速度から求めた中央気象署震度階級**

    **計測震度(相当値)** は気象庁の震度観測方法とは異なります。また、気象庁の検定を受けていないので、この値はあくまでも参考地です。  
   公表される地震情報の震度とは異なる値になる可能性があります。

4. 画面下のボタン  
   **「加速度,震度データをサーバー、ユーザーへ送信する」**  
   を押し、再度ボタンを押して停止させるかサイトを再読み込みするまで以下の情報が [P2P強震モニタ](https://anesewo.github.io/P2Pkyousin/monitor)に送信されます：
   - 起動時にランダムで決まるID
   - 加速度値  
   - 計測震度(相当値)  
   - 端末位置情報
   - 情報送信時刻
   - 過去10秒間の各方向の波形　　

  詳しくは[提供する情報について](https://github.com/anesewo/P2Pkyousin?tab=readme-ov-file#%E6%8F%90%E4%BE%9B%E3%81%99%E3%82%8B%E6%83%85%E5%A0%B1%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6)をお読みください



## 提供する情報について
- 送信される情報は **加速度値・計測震度(相当値)・端末位置情報（緯度経度は0.1度単位に丸めて送信）・情報送信時刻** です。  
- 送信は **利用者がボタンを押したときのみ行われ、自動送信はされません。**  
- 位置情報は **観測点の地域分布を把握する目的のみ** に利用され、個人の特定には用いられません。
- 情報送信時刻はそのデータが更新されているかを判断するために使用されます。  
- 提供される値は **公的機関の観測データではなく、あくまで簡易的な参考値** です。  
- **防災判断や避難行動の根拠には利用できません。**

## データの利用方法
turbowarpのサーバーを使用しているため **誰でも自由にアクセス** することができます。  
WSS接続でturbowarpのサーバーに接続し変数として取得します。方法は以下です。  
[turbowarp接続方法](https://docs.turbowarp.org/cloud-variables)  
各変数はay0~ay9という変数名です。名前が異なりますが、全て同じ形式です。  

次に、桁ごとに適切な処理を行います。  
具体的にはまず小数点の位置を求める必要があります。小数点の位置を仮にNとしたときに、

 - 観測点ID:1~Nまでの値がそのままID
 - 情報発信時刻:N+1~N+12桁の数をxとしたときにx÷100
 - 計測機器の緯度:N+13~N+15桁の数をxとしたときにx÷10
 - 計測機器の経度:N+16~N18桁の数をxとしたときにx÷10+86
 - 計測震度:N+19~N+21桁の数をxとしたときにx÷100-3
 - 最大加速度:N+22~N+26桁の数をxとしたときにx÷100
 - 各方向の過去10秒間の波形:N+27~最後までを使用している。詳しくは後。

です。補足や具体的な処理は[P2P強震モニタからWSで情報を受信する方法](https://scratch.mit.edu/projects/1222994571/)にて説明をしているのでお読みください

### 各方向の過去10秒間の波形
 - 各データの秒間は不明です。平均値にはなりますが、**10/各方向の加速度値データの長さ**で求められます。  
 - NS0～10秒→EW0～10秒→UD0～10の順に並んでいます。  
 - 各時間における加速度値は5桁ずつに対応しています。  

#### 手順
 N+27～最後まで の桁数を求め、3で割る。（ここでは仮に N+27～最後まで が3000桁として、1000とします。）  
ここで求められた数を使って、以下の通りに行うと各方向の元データが取得できます。  

 - NS方向:N+27+1000×0~N+26+1000×1
 - EW方向:N+27+1000×1~N+26+1000×2
 - NS方向:N+27+1000×2~N+26+1000×3

そして、ここで求められた各方向の元データを5桁ずつに分けます。  
それぞれ分けた結果をxとしてx/10-1000を行うことで、加速度のデータに変換されます。

## 禁止事項
- 本サービスの結果を **公式の情報であるかのように扱う行為**  
- その他、製作者が不適切と判断した行為  

※基本的にソフトの映像や観測データ、及び[データ送信](https://anesewo.github.io/P2Pkyousin/)は自由に利用可能です。データを送信する際に許可等を得る必要はありません。  
　加速度データをサーバーへ送信している際故意にデータ値を増幅させることは推奨されるものではありませんが、禁止ではありません。  
　ただし、P2P強震モニタ計測以外の外部からの変数の書き換えについては、混乱を生む確率がかなり上がるため、何かしらの対策を行う可能性があります。  
  
  なおソフト等にP2P強震モニタのデータを使用する際数値化,震度階級換算は自由です。ただし、上記したようにデータ値が実際の揺れではないものになっている可能性があることをご留意ください。
